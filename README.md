📱 QR Code Generator & Scanner (Python)

This project allows you to generate QR codes and scan QR codes using your webcam.
It is simple, fast, and beginner-friendly, using Python libraries like qrcode and opencv-python.

🚀 Features

Generate QR codes from text, messages, or URLs

Save QR code as an image (.png)

Scan QR codes in real-time using your laptop webcam

Extremely simple and easy to use

✅ Part 1: QR Code Generator
📌 Installation
pip install qrcode opencv-python

📌 Create File: qr_generator.py

▶ Run the Generator
python qr_generator.py


This will create a QR image named my_qr.png in your project folder.

✅ Part 2: QR Code Scanner (Webcam)
📌 Create File: qr_scanner.py

▶ Run the Scanner
python qr_scanner.py


This will open your webcam and detect QR codes live.
